Catatan Penting Mengenai Hasil Unduhan & Keterbatasan
  • Jika hanya file .pdf yang terunduh: Ekstensi berhasil mengunduh file dokumen cover asli dari penerbit, namun proses render/konversi menjadi file gambar (.png / .jpg) memerlukan waktu lebih lama atau mengalami timeout di peramban. File PDF tersebut tetap sah, valid, dan dapat Anda konversi seragam menggunakan tab "Konversi Folder PNG" di Dashboard.
  • Jika hanya file .htm / .html yang terunduh: Berkas dokumen tidak dapat diakses langsung oleh ekstensi. Hal ini biasanya menandakan bahwa artikel memerlukan akses jaringan kampus (seperti VPN, EzProxy, atau login SSO institusi), atau dokumen berada di balik batas akses berbayar (paywall).
  • Proses gagal atau dokumen bertuliskan "Cover" tidak ada: Untuk penerbit seperti IEEE Xplore, sistem otomatis menelusuri hingga halaman paling akhir prosiding dan mengambil dokumen prosiding/halaman depan jika kata "Cover" tidak ditemukan. Namun jika suatu tautan tetap gagal, Anda dapat menyalin daftar nomor yang error dengan tombol 1-klik di Dashboard.
  • Tantangan verifikasi robot (Cloudflare / CAPTCHA): Jika situs penerbit (seperti ACM Digital Library) menampilkan verifikasi "Verify you are human", tab peramban akan otomatis difokuskan. Silakan selesaikan centang verifikasi di tab tersebut; proses akan otomatis berlanjut setelah verifikasi selesai.

Panduan Instalasi di Google Chrome

1

Unduh & Ekstrak Berkas

Klik tombol "Unduh Ekstensi (.ZIP)" di atas. Setelah berkas ZIP terunduh, ekstrak (unzip) ke salah satu folder di komputer Anda (misalnya di folder Documents atau folder kerja Anda).

2

Buka Halaman Ekstensi Chrome

Buka peramban Google Chrome, ketik chrome://extensions/ pada bilah alamat (address bar), lalu tekan Enter.

3

Aktifkan Developer Mode

Di sudut kanan atas halaman ekstensi Chrome, aktifkan sakelar "Developer mode" (Mode Pengembang).

4

Muat Ekstensi (Load Unpacked)

Klik tombol "Load unpacked" (Muat yang belum dibongkar) yang muncul di sudut kiri atas halaman.

5

Pilih Folder Ekstensi

Pilih folder hasil ekstrak tadi (folder yang di dalamnya berisi berkas manifest.json). Ekstensi akan terpasang dan siap digunakan.

Cara Penggunaan & Fitur Dashboard

1

Buka Dashboard Ekstensi

Klik ikon ekstensi di pojok kanan atas Chrome, lalu pilih "Buka Dashboard Penuh" untuk membuka tampilan kerja yang leluasa.

2

Mode 1: Scraper Link (ID & Link dari Excel)

Siapkan daftar tautan Anda di Microsoft Excel atau Google Sheets dalam format 2 kolom sederhana:

Kolom A (ID) Kolom B (Link Scopus atau Publisher)
1 https://www.scopus.com/record/display.uri?eid=...
2 https://doi.org/10.1007/978-981-97-9097-5_15
3 https://ieeexplore.ieee.org/document/10826978/
4 https://doi.org/10.1145/3700706.3700723

Cukup salin (Copy) seluruh baris dan kolom tersebut dari Excel, lalu tempel (Paste) langsung ke kotak teks input di Dashboard. Setiap berkas sampul yang berhasil diunduh akan tersimpan di Downloads/book-covers/.

3

Mode 2: Konversi Folder PNG (Lokal)

Pilih tab "📁 Konversi Folder PNG" di Dashboard jika Anda sudah memiliki folder cover di komputer (berisi PDF, GIF, JPG, WebP). Anda dapat memilih folder atau drag-and-drop file langsung untuk mengonversi semuanya menjadi berkas .png seragam di Downloads/book-covers-png/.

4

Perekapan Error & Salin Nomor Cepat

Jika ada tautan/berkas yang gagal atau korup, kotak Log Error akan muncul secara otomatis. Anda dapat menekan tombol "📋 Salin Nomor Saja" untuk menyalin daftar nomor yang error (contoh: 3, 7, 12) untuk langsung ditempelkan ke laporan Excel Anda.
